# Creating a Development Branch

## Purpose
Keep production (main branch) stable while developing new features.
Pushes to main trigger redeployment; pushes to dev do not.

## Steps

1. Create and switch to dev branch:
   git checkout -b dev

2. Push dev branch to GitHub and set upstream tracking:
   git push -u origin dev

3. Do all development work on dev branch. Commits and pushes here won't affect production.

4. When ready to deploy to production, merge dev into main:
   git checkout main
   git merge dev
   git push

## Switching Between Branches

Switch to dev:
   git checkout dev

Switch to main:
   git checkout main

## Check Current Branch

   git branch

The branch with * is your current branch.
